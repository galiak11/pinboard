E1: Project Scaffold & Design System

Xcode Project UIKit Lifecycle Asset Catalogs Design Tokens

Problem

You're starting a new iOS app called PinBoard. Create the project in Xcode, remove the default storyboard-based launch flow, set up a programmatic UIKit lifecycle with a UINavigationController as root, organize the source files into a clean folder structure, and establish a design system with semantic color tokens and typography that support light/dark mode and Dynamic Type.

By the end of this exercise, the app should build, launch on a simulator, and display an empty screen with your themed background color.

What the Solution Looks Like

An Xcode project created via File → New → Project, stripped of storyboards, with a programmatic SceneDelegate that creates a UIWindow with a UINavigationController. Source files organized into feature-based groups. An asset catalog with color sets for light/dark mode. AppColors and AppFonts enums providing semantic design tokens throughout the app.

Steps

Step 1 Create the Xcode project

In Xcode: File → New → Project → App. Configure:

  • Product Name: PinBoard
  • Interface: Storyboard
  • Language: Swift
  • Check Include Tests
  • Uncheck "Create Git repository on my Mac" — your cloned fork is already a git repo

Save the project inside your cloned repo folder so it sits alongside the exercises/ directory. Xcode will automatically detect the existing git repo and show file change indicators in the Project Navigator.

Verify it builds and runs on the simulator — you'll see a blank white screen from the default storyboard.

Step 2 Remove storyboards and go programmatic

The default project uses Main.storyboard to instantiate the initial view controller. Switch to a fully programmatic setup:

  1. Delete Main.storyboard (move to trash)
  2. Delete the default ViewController.swift
  3. In the target's Info tab (or Info.plist): remove the Main storyboard file base name entry
  4. In Info → Application Scene Manifest → Scene Configuration → Default Configuration: remove the Storyboard Name entry

Update AppDelegate.swift and SceneDelegate.swift to create the window programmatically. Build and run — you should see an empty screen (no crash, no storyboard errors).

Hint: Info.plist storyboard removal

If editing Info.plist as source code, remove these keys:

<!-- Remove this from the top level -->
<key>UIMainStoryboardFile</key>
<string>Main</string>

<!-- Inside UIApplicationSceneManifest → UISceneConfigurations → UIWindowSceneSessionRoleApplication, remove: -->
<key>UISceneStoryboardFile</key>
<string>Main</string>

Alternatively, in the target's General tab, clear the "Main Interface" field.

Solution: AppDelegate.swift 
import UIKit

@main
class AppDelegate: UIResponder, UIApplicationDelegate {
    func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        return true
    }

    func application(
        _ application: UIApplication,
        configurationForConnecting connectingSceneSession: UISceneSession,
        options: UIScene.ConnectionOptions
    ) -> UISceneConfiguration {
        UISceneConfiguration(name: "Default Configuration", sessionRole: connectingSceneSession.role)
    }
}
Solution: SceneDelegate.swift 
import UIKit

class SceneDelegate: UIResponder, UIWindowSceneDelegate {
    var window: UIWindow?

    func scene(
        _ scene: UIScene,
        willConnectTo session: UISceneSession,
        options connectionOptions: UIScene.ConnectionOptions
    ) {
        guard let windowScene = scene as? UIWindowScene else { return }
        let window = UIWindow(windowScene: windowScene)
        let nav = UINavigationController()
        window.rootViewController = nav
        window.makeKeyAndVisible()
        self.window = window
    }
}
Step 3 Organize the folder structure

Create Xcode groups (backed by real folders) to organize the project for the features we'll build:

PinBoard/
├── App/
│   └── Coordinators/
├── Features/
│   ├── HomeFeed/
│   └── PinDetail/
├── Core/
│   ├── Networking/
│   └── Models/
├── DesignSystem/
└── Resources/
    └── Assets.xcassets (move existing one here)

PinBoardTests/
├── Core/
├── Features/
│   ├── HomeFeed/
│   └── PinDetail/
├── App/
├── Mocks/
└── Fixtures/

Move AppDelegate.swift and SceneDelegate.swift into PinBoard/App/. Move Assets.xcassets and Info.plist into PinBoard/Resources/. Make sure the project still builds after reorganizing.

Hint: Creating folder-backed groups in Xcode

In Xcode's Project Navigator, right-click the PinBoard group → New Group. Name it (e.g., "App"). Xcode creates both the group and a matching folder on disk. Drag existing files into the new groups. If Xcode shows files in red, check that the file's location matches via the File Inspector (right panel).

You can also create folders in Finder first, then drag them into Xcode and choose "Create groups."

Step 4 Create the design system

Add color sets to Assets.xcassets (via Xcode's asset catalog editor) with light and dark variants for: Primary, Secondary, Background, Surface, OnSurface, OnSurfaceSecondary, Error, Divider.

Create DesignSystem/Colors.swift — an AppColors enum with static properties that load from the asset catalog with system fallbacks.

Create DesignSystem/Fonts.swift — an AppFonts enum with static properties using UIFont.preferredFont(forTextStyle:) for: heading (.title2), subheading (.headline), body (.body), caption (.caption1), label (.footnote).

Set the navigation controller's view background to AppColors.background in SceneDelegate to verify theming works. Toggle dark mode in the simulator (Cmd+Shift+A) to confirm both variants load.

Solution: Colors.swift 
import UIKit

enum AppColors {
    static let primary = UIColor(named: "Primary") ?? .systemRed
    static let secondary = UIColor(named: "Secondary") ?? .secondaryLabel
    static let background = UIColor(named: "Background") ?? .systemBackground
    static let surface = UIColor(named: "Surface") ?? .secondarySystemBackground
    static let onSurface = UIColor(named: "OnSurface") ?? .label
    static let onSurfaceSecondary = UIColor(named: "OnSurfaceSecondary") ?? .secondaryLabel
    static let error = UIColor(named: "Error") ?? .systemRed
    static let divider = UIColor(named: "Divider") ?? .separator
}
Solution: Fonts.swift 
import UIKit

enum AppFonts {
    static let heading = UIFont.preferredFont(forTextStyle: .title2)
    static let subheading = UIFont.preferredFont(forTextStyle: .headline)
    static let body = UIFont.preferredFont(forTextStyle: .body)
    static let caption = UIFont.preferredFont(forTextStyle: .caption1)
    static let label = UIFont.preferredFont(forTextStyle: .footnote)
}
Solution: SceneDelegate.swift (updated with design system) 
import UIKit

class SceneDelegate: UIResponder, UIWindowSceneDelegate {
    var window: UIWindow?

    func scene(
        _ scene: UIScene,
        willConnectTo session: UISceneSession,
        options connectionOptions: UIScene.ConnectionOptions
    ) {
        guard let windowScene = scene as? UIWindowScene else { return }
        let window = UIWindow(windowScene: windowScene)
        let nav = UINavigationController()
        nav.view.backgroundColor = AppColors.background
        window.rootViewController = nav
        window.makeKeyAndVisible()
        self.window = window
    }
}
