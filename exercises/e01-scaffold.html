E1: Project Scaffold & Design System

XcodeGen UIKit Lifecycle Asset Catalogs Design Tokens

Problem

You're starting a new iOS app called PinBoard. Set up the project using XcodeGen (not Xcode's GUI project wizard), create the app lifecycle files, and establish a design system with semantic color tokens and typography that support light/dark mode and Dynamic Type.

By the end of this exercise, the app should build, launch on a simulator, and display an empty screen with your themed background color.

What the Solution Looks Like

A project.yml that generates a valid Xcode project with xcodegen generate. An AppDelegate and SceneDelegate that create a UIWindow. An asset catalog with color sets for light/dark mode. AppColors and AppFonts enums providing semantic design tokens throughout the app.

Steps

Step 1 Create project.yml and directory structure

Define an iOS app target called PinBoard (iOS 16.0+, Swift 5.9) and a test target PinBoardTests. Create the folder structure:

PinBoard/
├── App/
│   └── Coordinators/
├── Features/
│   ├── HomeFeed/
│   └── PinDetail/
├── Core/
│   ├── Networking/
│   └── Models/
├── DesignSystem/
└── Resources/
    └── Assets.xcassets/

PinBoardTests/
├── Core/
├── Features/
│   ├── HomeFeed/
│   └── PinDetail/
├── App/
├── Mocks/
└── Fixtures/

Run xcodegen generate and verify the project opens in Xcode.

name: PinBoard

    iOS: "16.0"

  PinBoardTests:
    type: bundle.unit-test
    platform: iOS
    sources: [PinBoardTests]
    dependencies:
      - target: PinBoard
Step 2 Create AppDelegate and SceneDelegate

Minimal app lifecycle. AppDelegate returns the default scene configuration. SceneDelegate creates a UIWindow, sets a UINavigationController as its root view controller, and makes it key and visible.

The app should launch and show an empty screen.

Hint: SceneDelegate setup

In scene(_:willConnectTo:options:):

guard let windowScene = (scene as? UIWindowScene) else { return }
let window = UIWindow(windowScene: windowScene)
let nav = UINavigationController()
window.rootViewController = nav
window.makeKeyAndVisible()
self.window = window
Step 3 Create the design system

Add color sets to Assets.xcassets with light and dark variants for: Primary, Secondary, Background, Surface, OnSurface, OnSurfaceSecondary, Error, Divider.

Create AppColors enum with static properties returning UIColor(named:) for each token.

Create AppFonts enum with static properties using UIFont.preferredFont(forTextStyle:) for: heading (.title2), subheading (.headline), body (.body), caption (.caption1), label (.footnote).

Set the navigation controller's view background to AppColors.background to verify theming works.

Hint: Asset catalog color sets

Each color set in Assets.xcassets needs a Contents.json with both "Any" and "Dark" appearances. Create folders like Assets.xcassets/Colors/Primary.colorset/.

Alternatively, add colors through Xcode's asset catalog GUI — easier for picking color values.
