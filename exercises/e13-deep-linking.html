E13: Deep Linking & Scoped DI Containers

URL Schemes Route Parsing Scoped Containers Coordinator Navigation Requires E10, E4

Problem

The app should respond to custom URL schemes like pinboard://home and pinboard://photo/abc-123. Additionally, the flat DI container passes too much context — split it into scoped containers where each feature gets its own container that holds feature-specific services while delegating shared services to the parent.

What the Solution Looks Like

AppRoute enum parses URLs into typed routes. Coordinators implement navigate(to:) cascading from App → MainTab → HomeFeed. Scoped containers (HomeFeedDependencyContainer, PinDetailDependencyContainer) replace direct access to the root container in feature coordinators.

Steps

Step 1 Create AppRoute

An enum with cases .home and .photoDetail(id: String). Failable init?(url: URL) that:

  • Checks scheme is pinboard
  • Parses host: "home" → .home, "photo" → extract ID from path
  • Returns nil for unknown hosts, invalid schemes, or missing IDs

Conform to Equatable for easy testing.

Step 2 Create scoped DI containers

HomeFeedDependencyContainer:

  • Holds reference to parent: AppDependencyContainer
  • Exposes apiClient and imageCache via parent (computed properties)
  • Owns homeFeedService: HomeFeedServiceProtocol (lazy)
  • Factory: makePinDetailContainer(photoID:)

PinDetailDependencyContainer:

  • Holds reference to parent + photoID: String
  • Exposes shared services via parent
  • Owns pinDetailService: PinDetailServiceProtocol (lazy)

Add factory methods on AppDependencyContainer: makeHomeFeedContainer(), makePinDetailContainer(photoID:).

Step 3 Update coordinators for scoped containers

Change HomeFeedCoordinator to take HomeFeedDependencyContainer instead of AppDependencyContainer. Change PinDetailCoordinator to take PinDetailDependencyContainer. Update the container references and factory calls throughout.

Step 4 Implement navigate chain

Add navigate(to route: AppRoute) to coordinators:

  • AppCoordinator: delegates to mainTabCoordinator.navigate(to:)
  • MainTabCoordinator: for .home → select home tab. For .photoDetail(id:) → select home tab, pop to root, call homeFeedCoordinator.showPhotoDetail(id:)
  • Extract showPhotoDetail(id:) as a public method on HomeFeedCoordinator
Step 5 Wire SceneDelegate

Handle URLs at launch in scene(_:willConnectTo:options:) — check connectionOptions.urlContexts. Handle URLs at runtime in scene(_:openURLContexts:). Both parse URL → AppRoute → appCoordinator.navigate(to:).

Step 6 Write tests

AppRouteTests:

  • pinboard://home → .home
  • pinboard://photo/abc-123 → .photoDetail(id: "abc-123")
  • https://photo/abc → nil (wrong scheme)
  • pinboard://settings → nil (unknown host)
  • pinboard://photo → nil (missing ID)

Update coordinator tests to use the new scoped containers.
