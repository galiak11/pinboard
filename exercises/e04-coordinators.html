E4: Coordinator Pattern & DI Container

Coordinator Protocol Child Management Dependency Injection Composition Root Requires E1

Problem

View controllers shouldn't know how to navigate — that creates tight coupling and makes testing difficult. Implement the Coordinator pattern to centralize navigation logic outside of VCs. Also create a root dependency injection container (composition root) that owns shared services and provides them to the rest of the app.

What the Solution Looks Like

A Coordinator protocol with start(), childCoordinators, and helper methods. An AppDependencyContainer that creates the APIClient and will later provide feature-level services. An AppCoordinator that owns the window, sets the root VC, and manages child coordinators. The SceneDelegate creates the container and coordinator.

Steps

Step 1 Define the Coordinator protocol

Create Coordinator protocol with:

  • var navigationController: UINavigationController { get }
  • var childCoordinators: [Coordinator] { get set }
  • func start()

Add extension methods: addChild(_:) appends to the array, removeChild(_:) removes by identity (===). Use AnyObject constraint so coordinators are reference types.

Step 2 Create AppDependencyContainer

The composition root. Creates and owns the APIClient using Secrets.unsplashAccessKey and the Unsplash base URL. For now it just has apiClient: APIClientProtocol — feature services will be added in later exercises.

Step 3 Create AppCoordinator

Takes a UIWindow, UINavigationController, and AppDependencyContainer. start() sets the window's rootViewController to the nav controller and calls window.makeKeyAndVisible(). For now, it just shows an empty nav — feature coordinators come in E6.

Step 4 Wire SceneDelegate

Update SceneDelegate to create the container and coordinator:

let container = AppDependencyContainer()
let navController = UINavigationController()
let coordinator = AppCoordinator(window: window, navigationController: navController, container: container)
coordinator.start()
Step 5 Write tests

AppCoordinatorTests: verify that start() sets the window's root view controller, and that a child coordinator slot exists (empty at first).

Success Criteria

LevelCriteria
MinimalApp launches via coordinator → container → SceneDelegate chain. Coordinator tests pass.
ExtendedaddChild/removeChild work correctly with identity-based comparison. Container initializes APIClient with real credentials.

Solution: Coordinator.swift 
import UIKit

    protocol Coordinator: AnyObject {
      var navigationController: UINavigationController { get }
      var childCoordinators: [Coordinator] { get set }
      func start()
    }

    extension Coordinator {
      func addChild(_ coordinator: Coordinator) {
        childCoordinators.append(coordinator)
      }

      func removeChild(_ coordinator: Coordinator) {
        childCoordinators.removeAll { $0 === coordinator }
      }
    }
Solution: AppCoordinator.swift 
import UIKit

    final class AppCoordinator: Coordinator {
      private let window: UIWindow
      let navigationController: UINavigationController
      var childCoordinators: [Coordinator] = []
      private let container: AppDependencyContainer

      init(window: UIWindow, navigationController: UINavigationController, container: AppDependencyContainer) {
        self.window = window
        self.navigationController = navigationController
        self.container = container
      }

      func start() {
        window.rootViewController = navigationController
        window.makeKeyAndVisible()
      }
    }
Solution: AppDependencyContainer.swift 
import Foundation

    final class AppDependencyContainer {
      let apiClient: APIClientProtocol

      init() {
        let baseURL = URL(string: "https://api.unsplash.com")!
        apiClient = APIClient(baseURL: baseURL, accessKey: Secrets.unsplashAccessKey)
      }

      // Factory methods for scoped containers (added in E13)
      func makeHomeFeedContainer() -> HomeFeedDependencyContainer {
        HomeFeedDependencyContainer(parent: self)
      }
    }
Solution: SceneDelegate.swift 
import UIKit

    class SceneDelegate: UIResponder, UIWindowSceneDelegate {
      var window: UIWindow?
      private var appCoordinator: AppCoordinator?

      func scene(_ scene: UIScene, willConnectTo session: UISceneSession, options connectionOptions: UIScene.ConnectionOptions) {
        guard let windowScene = scene as? UIWindowScene else { return }
        let window = UIWindow(windowScene: windowScene)
        let container = AppDependencyContainer()
        let nav = UINavigationController()
        let coordinator = AppCoordinator(window: window, navigationController: nav, container: container)
        self.window = window
        self.appCoordinator = coordinator
        coordinator.start()
      }
    }
Solution: AppCoordinatorTests.swift 
import XCTest
    @testable import PinBoard

    final class AppCoordinatorTests: XCTestCase {
      func test_start_setsWindowRootViewController() {
        let window = UIWindow()
        let nav = UINavigationController()
        let container = AppDependencyContainer()
        let sut = AppCoordinator(window: window, navigationController: nav, container: container)

        sut.start()

        XCTAssertTrue(window.rootViewController === nav)
        XCTAssertEqual(sut.childCoordinators.count, 0)
      }
    }
