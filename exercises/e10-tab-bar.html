E10: Tab Bar Navigation

UITabBarController Coordinator Hierarchy Requires E6, E9

Problem

The app launches directly into the home feed. Real apps use tab bars for top-level navigation. Create a MainTabCoordinator that manages a UITabBarController with a Home tab (the existing feed) and a Search tab (placeholder). Refactor AppCoordinator to delegate to the tab coordinator.

What the Solution Looks Like

MainTabCoordinator creates a tab bar controller with two tabs. The first tab runs HomeFeedCoordinator in its own navigation controller. The second tab is a placeholder VC. AppCoordinator creates MainTabCoordinator instead of HomeFeedCoordinator directly.

Steps

Step 1 Create MainTabCoordinator

Creates a UITabBarController with two tabs:

  • Home: a new UINavigationController with HomeFeedCoordinator. Tab bar item: "Home" with house SF Symbol.
  • Search: a placeholder UIViewController with a "Coming soon" label. Tab bar item: "Search" with magnifyingglass SF Symbol.

Store a reference to homeFeedCoordinator for later use (deep linking in E13).

Step 2 Refactor AppCoordinator

Instead of creating HomeFeedCoordinator directly, create MainTabCoordinator as a child. Push the tab bar controller onto the window's navigation controller (or set it directly as root). Store a reference to the MainTabCoordinator.

Step 3 Write tests

MainTabCoordinatorTests:

  • start() creates a tab bar controller with 2 tabs
  • First tab contains a HomeFeedViewController
  • HomeFeedCoordinator is added as a child coordinator

Success Criteria

LevelCriteria
MinimalApp shows tab bar with Home and Search tabs. Home tab shows the feed. Tests pass.
ExtendedTab bar items have correct SF Symbol icons and titles. Photo detail still pushes correctly within the Home tab's nav stack.
