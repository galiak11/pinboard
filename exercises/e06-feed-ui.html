E6: Home Feed UI

UICollectionView CompositionalLayout DiffableDataSource Custom Cells Delegation Requires E5

Problem

Build the Home Feed screen — a scrollable grid of photo cards. Start simple (basic collection view with default cells), then progressively upgrade to a custom cell, diffable data source, and waterfall layout. Wire navigation through a coordinator rather than coupling it to the VC.

What the Solution Looks Like

A HomeFeedViewController with a 2-column waterfall grid using UICollectionViewCompositionalLayout and UICollectionViewDiffableDataSource. A custom PhotoCell showing a colored placeholder (images come in E7). A HomeFeedCoordinator that creates the VC and handles navigation via HomeFeedDelegate.

Steps

Step 1 Basic VC with collection view and default cells

Create HomeFeedViewController with a UICollectionView using UICollectionViewFlowLayout. Register a basic UICollectionViewCell using CellRegistration. In the cell, just show the photo title in a label.

Bind to the ViewModel: on onPhotosUpdated, store the cell view models and call reloadData(). On onStateChanged, show/hide a UIActivityIndicatorView. Call viewModel.viewDidLoad() in viewDidLoad().

Temporarily wire it directly in AppCoordinator to see it on screen.

Step 2 Custom PhotoCell

Create PhotoCell: a UICollectionViewCell subclass with a full-bleed UIImageView and a semi-transparent bottom overlay containing the photo title. Use auto-layout to pin the image view to all edges.

configure(with: PhotoCellViewModel) sets the title. For now, set the image view's background color based on the aspect ratio (just to visualize cell sizes). Implement prepareForReuse() to reset the image and title.

Step 3 Diffable data source

Replace the UICollectionViewDataSource methods with a UICollectionViewDiffableDataSource<Section, String>. Define a Section enum with .main. The cell provider closure dequeues PhotoCell and configures it.

On onPhotosUpdated, build a NSDiffableDataSourceSnapshot from the cell view model IDs and apply() it.

Step 4 Waterfall compositional layout

Create WaterfallLayout — a factory that builds a UICollectionViewCompositionalLayout using the NSCollectionLayoutSection provider closure. 2 columns. Item heights are calculated from aspect ratios (you'll need a callback to get the aspect ratio for an index). 8pt inter-item spacing, 8pt section insets.

Replace the flow layout with the waterfall layout in the VC.

Hint: Waterfall layout approach

CompositionalLayout doesn't have built-in waterfall support. The common approach is to use a custom NSCollectionLayoutSection provider that pre-calculates item positions using column heights tracking, similar to how Pinterest's layout works. Each item is an NSCollectionLayoutGroupCustomItem with an absolute frame.

UICollectionViewCompositionalLayout { sectionIndex, environment in
    let items = // calculate frames for each item
    let group = NSCollectionLayoutGroup.custom(layoutSize: groupSize) { _ in items }
    return NSCollectionLayoutSection(group: group)
}
Step 5 HomeFeedCoordinator and delegate

Create HomeFeedDelegate protocol with homeFeedDidSelectPhoto(id: String). Create HomeFeedCoordinator that:

  • Creates the ViewModel (with the service from the container) and ViewController
  • Conforms to HomeFeedDelegate
  • On photo selection, prints the ID (detail screen comes in E9)

Wire didSelectItemAt in the VC to call the delegate.

Step 6 Wire into app navigation

Update AppCoordinator.start() to create HomeFeedCoordinator as a child, passing the container and navigation controller. Remove any temporary wiring from Step 1.

Step 7 Write tests

HomeFeedCoordinatorTests: verify start() pushes a HomeFeedViewController. Create MockHomeFeedDelegate to verify delegate calls.
