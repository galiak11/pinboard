E12: State & Error Handling

Empty States Inline Errors Reusable Components Cell Placeholders Requires E6, E9, E11

Problem

The app has no visual feedback for empty results or errors. Network failures produce no UI response. Build a reusable overlay view for empty/error states, add context-aware error handling (full-screen when no data, subtle when data exists), and handle image loading failures in cells with a placeholder.

What the Solution Looks Like

A StateOverlayView with configurable styles (empty, error) including icon, message, and retry button. The home feed shows an empty state when the API returns no photos. Errors show as full-screen overlays when there's no data, or preserve existing content when data already loaded. PhotoCell shows a system image placeholder on image load failure.

Steps

Step 1 Create StateOverlayView

A reusable UIView subclass with:

  • A large SF Symbol icon (UIImageView)
  • A title label (heading font)
  • A message label (body font, multiline)
  • A "Retry" button (visible only for error style)
  • var onRetry: (() -> Void)? closure

Configurable via enum Style:

  • .empty(message: String) — shows photo.on.rectangle icon, "No Results" title, custom message, no retry button
  • .error(message: String) — shows exclamationmark.triangle icon, "Something Went Wrong" title, custom message, retry button

Center the content vertically and horizontally with auto-layout.

Step 2 Add empty state to Home Feed

When the state is .loaded(hasMore: false) and cellViewModels is empty, add a StateOverlayView with .empty(message: "No photos found") over the collection view. Hide it when data arrives.

Step 3 Add inline errors to Home Feed

Context-aware error handling:

  • No data + error: show full-screen StateOverlayView with .error style. Wire retry to viewModel.viewDidLoad().
  • Data exists + error: keep existing data visible. The user can still browse what's loaded. Optionally log the error or update the footer.
Step 4 Add error state to Pin Detail

Replace any alert-based error with an inline StateOverlayView in PinDetailViewController. Wire retry to viewModel.viewDidLoad().

Step 5 Cell failure placeholder

In PhotoCell.configure(), handle the Nuke image load failure callback. On failure, show UIImage(systemName: "photo") with .scaleAspectFit content mode and a muted tint color. Reset the placeholder in prepareForReuse().

Hint: Nuke failure handling 
NukeExtensions.loadImage(with: url, into: imageView) { [weak self] result in
    if case .failure = result {
        self?.imageView.contentMode = .scaleAspectFit
        self?.imageView.tintColor = AppColors.onSurfaceSecondary
        self?.imageView.image = UIImage(systemName: "photo")
    }
}
