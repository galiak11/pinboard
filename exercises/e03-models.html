E3: Data Models & JSON Fixtures

Codable CodingKeys Nested JSON Test Fixtures Requires E2

Problem

Create Decodable models for the Unsplash API responses. The API returns snake_case JSON with nested objects (urls, user, exif). Use real API response samples as test fixtures to ensure your models handle all fields correctly — including optional ones like description, exif, and location.

What the Solution Looks Like

UnsplashPhoto and UnsplashUser structs with CodingKeys for snake_case mapping. JSON fixture files containing sanitized real API responses. A Fixtures helper for loading test data. Decoding tests that verify every field.

Steps

Step 1 Create UnsplashPhoto and UnsplashUser models

UnsplashPhoto fields: id, description (optional), urls (nested: raw, full, regular, small, thumb), width, height, likes, user: UnsplashUser, createdAt (String). For the detail endpoint, also: exif (optional, nested: make, model, aperture, exposureTime, focalLength, iso) and location (optional).

UnsplashUser fields: name, username, profileImage (nested: small, medium, large).

Use CodingKeys for snake_case → camelCase mapping (e.g., created_at → createdAt, profile_image → profileImage).

    Hint: Bundle loading for test fixtures
    


private class TestBundleAnchor {}

enum Fixtures {
    static func loadFixture(_ name: String) -> Data {
        let bundle = Bundle(for: TestBundleAnchor.self)
        let url = bundle.url(forResource: name, withExtension: "json")!
        return try! Data(contentsOf: url)
    }
}

import XCTest
        @testable import PinBoard

        final class ModelDecodingTests: XCTestCase {
          func test_decodePhotosPage() throws {
            let data = Fixtures.loadFixture("photos_page1")
            let photos = try JSONDecoder().decode([UnsplashPhoto].self, from: data)
            XCTAssertGreaterThan(photos.count, 0)
            XCTAssertEqual(photos.first?.id, "") // update with expected ID from fixture
            XCTAssertNotNil(photos.first?.urls.regular)
            XCTAssertNotNil(photos.first?.user.name)
          }

          func test_decodePhotoDetail() throws {
            let data = Fixtures.loadFixture("photo_detail")
            let photo = try JSONDecoder().decode(UnsplashPhoto.self, from: data)
            XCTAssertNotNil(photo.exif)
            XCTAssertNotNil(photo.location)
          }
        }
  • Decode photos_page1.json into [UnsplashPhoto] — verify count, first photo's ID, URLs, user name
  • Decode photo_detail.json into UnsplashPhoto — verify all fields including exif when present
  • Test a photo with nil description and nil exif — verify they decode as nil without error
