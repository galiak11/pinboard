E9: Pin Detail (Full Vertical Slice)

Feature Composition Vertical Slice Coordinator Lifecycle Requires E6, E7, E8

Problem

Tapping a photo in the feed should push a detail screen. Build this as a complete vertical slice — service, view model, view controller, coordinator — applying every pattern established in previous exercises. The detail screen shows the full-resolution image, description, author, likes, date, and EXIF data.

What the Solution Looks Like

PinDetailService fetching /photos/:id. PinDetailViewModel with a DetailState enum. PinDetailViewController with a scroll view layout. PinDetailCoordinator created by the home feed coordinator on photo selection, with onDismiss cleanup.

Steps

Step 1 Create PinDetailService

Define PinDetailServiceProtocol with func fetchPhoto(id: String) async throws -> UnsplashPhoto. Implement PinDetailService calling the .photo(id:) endpoint. Register on the container (add a factory makePinDetailService() or a property).

Step 2 Create PinDetailViewModel

DetailState: .idle, .loading, .loaded, .error(String). Input: viewDidLoad(). Output properties (via closures):

  • imageURL: URL? — uses urls.regular for full-width display
  • titleText: String — photo description or fallback
  • authorName: String, authorImageURL: URL?
  • likesText: String — formatted count
  • dateText: String — "Jan 15, 2025" or relative
  • exifText: String? — "Canon EOS R5 · f/2.8 · 1/500s · ISO 400" (graceful with nil fields)
Hint: EXIF formatting with optional fields 
func formatExif(_ exif: UnsplashPhoto.Exif?) -> String? {
    guard let exif = exif else { return nil }
    let parts = [
        exif.make.flatMap { m in exif.model.map { "\(m) \($0)" } ?? m },
        exif.aperture.map { "f/\($0)" },
        exif.exposureTime.map { "\($0)s" },
        exif.iso.map { "ISO \($0)" }
    ].compactMap { $0 }
    return parts.isEmpty ? nil : parts.joined(separator: " · ")
}
Step 3 Create PinDetailViewController

A scroll view layout with:

  • Full-width image view (height from aspect ratio)
  • Title label (heading font)
  • Description label (body font, optional)
  • Author row: small avatar image + name label
  • Metadata: likes, date, EXIF (caption font)

Bind to ViewModel closures to update UI on state changes. Show a loading spinner during .loading.

Step 4 Create PinDetailCoordinator

Takes navigation controller, photo ID, and container. Creates service, VM, VC. start() pushes the VC. Has var onDismiss: (() -> Void)? called in deinit — this lets the parent clean up its child coordinator reference.

Step 5 Wire photo selection

In HomeFeedCoordinator.homeFeedDidSelectPhoto(id:): create PinDetailCoordinator, add as child, set onDismiss to remove it from children, call start().

Step 6 Write tests

Create MockPinDetailService. Tests:

  • PinDetailServiceTests: correct endpoint, response mapping, error propagation
  • PinDetailViewModelTests: state transitions, date formatting, EXIF with partial fields, nil description
  • PinDetailCoordinatorTests: start pushes VC, deinit calls onDismiss
