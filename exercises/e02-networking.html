E2: Networking Layer

Protocol Design URLSession async/await Generics Requires E1

Problem

Build a protocol-oriented networking layer that constructs URLs from endpoint definitions, makes authenticated requests to the Unsplash API, and handles errors with typed error cases. Design it so every piece is independently testable — endpoints can be tested without URLSession, and the API client can be tested with a stubbed URLProtocol.

What the Solution Looks Like

An Endpoint protocol that describes API calls declaratively (path, method, query items). An APIClient that takes any Endpoint, builds a URLRequest with auth headers, and decodes the response using generics. An APIError enum for typed error handling. A MockURLProtocol for testing real URLSession behavior without the network. A MockAPIClient for use by higher-layer tests.

Steps

Step 1 Define Endpoint protocol and APIError

Create Endpoint protocol with properties: path: String, method: String (default "GET"), queryItems: [URLQueryItem] (default empty). Add a method urlRequest(baseURL: URL, accessKey: String) -> URLRequest that builds the full URL, adds query items, sets the HTTP method, and adds the Authorization: Client-ID <key> header.

Create APIError enum conforming to LocalizedError with cases: httpError(statusCode: Int), decodingError, networkError(Error), unknown.

Hint: Endpoint protocol with default implementation 
protocol Endpoint {
    var path: String { get }
    var method: String { get }
    var queryItems: [URLQueryItem] { get }
}

extension Endpoint {
    var method: String { "GET" }
    var queryItems: [URLQueryItem] { [] }

    func urlRequest(baseURL: URL, accessKey: String) -> URLRequest {
        var components = URLComponents(url: baseURL.appendingPathComponent(path), resolvingAgainstBaseURL: true)!
        if !queryItems.isEmpty { components.queryItems = queryItems }
        var request = URLRequest(url: components.url!)
        request.httpMethod = method
        request.setValue("Client-ID \(accessKey)", forHTTPHeaderField: "Authorization")
        return request
    }
}
Step 2 Implement Unsplash endpoints

Create UnsplashEndpoint enum with cases:

  • .photos(page: Int) — path: /photos, query: page, per_page=20, order_by=popular
  • .photo(id: String) — path: /photos/{id}, no query items
Step 3 Create APIClient with protocol

Define APIClientProtocol:

protocol APIClientProtocol {
    func request<T: Decodable>(_ endpoint: any Endpoint) async throws -> T
}

Implement APIClient: takes baseURL, accessKey, and an optional URLSession (for test injection). In request(): build the URLRequest from the endpoint, call URLSession.data(for:), check the HTTP status code (2xx = success, else throw .httpError), decode with JSONDecoder (catch decoding errors as .decodingError).

Step 4 Add Secrets

Create Secrets.example.swift (committed) with a placeholder key. Create Secrets.swift (gitignored) with your real Unsplash access key. Both define an enum Secrets with static let unsplashAccessKey.

Step 5 Write tests

Create MockURLProtocol: a URLProtocol subclass with static stubs for data, response, and error. Override startLoading() to return the stubbed values.

Create MockAPIClient: conforms to APIClientProtocol, stores a stubbedResult: Result<Any, Error> and records requestedEndpoints.

Write UnsplashEndpointsTests: verify paths, query items, HTTP methods for both endpoints.

Write APIClientTests (XCTest, using MockURLProtocol): test success decoding, HTTP error responses, invalid JSON, network errors, and that the auth header is injected.

Hint: MockURLProtocol pattern 
final class MockURLProtocol: URLProtocol {
    static var stubbedData: Data?
    static var stubbedResponse: HTTPURLResponse?
    static var stubbedError: Error?

    override class func canInit(with request: URLRequest) -> Bool { true }
    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }

    override func startLoading() {
        if let error = Self.stubbedError {
            client?.urlProtocol(self, didFailWithError: error)
        } else {
            if let response = Self.stubbedResponse {
                client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
            }
            if let data = Self.stubbedData {
                client?.urlProtocol(self, didLoad: data)
            }
            client?.urlProtocolDidFinishLoading(self)
        }
    }

    override func stopLoading() {}
}
