Workflow

  1. Read the exercise page
  2. Think about how you'd approach the problem before reading the steps
  3. Implement each step — every step leaves the project buildable
  4. Run tests: Cmd+U in Xcode
  5. Commit and push with the suggested commit message
  6. Click the checkbox to mark the exercise complete
