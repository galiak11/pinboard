E7: Image Loading & Caching

SPM Nuke Prefetching Caching Protocol Requires E6

Problem

The feed shows colored placeholders instead of real photos. Integrate the Nuke image loading library to download and display images efficiently, add prefetching so images load before cells scroll into view, and create a caching protocol that abstracts Nuke's implementation.

What the Solution Looks Like

Nuke added as an SPM dependency. PhotoCell loads images via NukeExtensions.loadImage(with:into:) with automatic cancellation on reuse. HomeFeedViewController implements UICollectionViewDataSourcePrefetching with Nuke's ImagePrefetcher. An ImageCaching protocol wrapping Nuke's pipeline cache, registered on the DI container.

Steps

Step 1 Add Nuke as SPM dependency

Update project.yml to add Nuke as a Swift Package dependency:

packages:
  Nuke:
    url: https://github.com/kean/Nuke
    from: "12.0.0"

# In the PinBoard target:
dependencies:
  - package: Nuke
    product: Nuke
  - package: Nuke
    product: NukeExtensions
  - package: Nuke
    product: NukeUI

Run xcodegen generate, open the project, and verify import Nuke compiles.

Step 2 Load images in PhotoCell

In PhotoCell.configure(with:), replace the placeholder background color with real image loading:

import NukeExtensions

NukeExtensions.loadImage(with: viewModel.imageURL, into: imageView)

This automatically cancels the previous request when the cell is reused. Set imageView.contentMode = .scaleAspectFill and clipsToBounds = true.

Step 3 Add prefetching

Make HomeFeedViewController conform to UICollectionViewDataSourcePrefetching. Create a lazy var prefetcher = ImagePrefetcher(). Map index paths to image URLs and call prefetcher.startPrefetching(with:) / stopPrefetching(with:). Set collectionView.prefetchDataSource = self.

Step 4 Create ImageCaching protocol

Define a protocol to abstract image caching away from Nuke's API:

protocol ImageCaching {
    func cachedImage(for url: URL) -> UIImage?
    func store(_ image: UIImage, for url: URL)
    func removeAll()
}

Implement NukeImageCache wrapping ImagePipeline.cache. Add imageCache: ImageCaching to AppDependencyContainer.

Step 5 Write tests

ImageCachingTests: store an image and retrieve it, call removeAll() and verify cache is empty, verify a cache miss returns nil.
